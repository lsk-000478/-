# 刘少康的个人网站

> 让真实的故事，被更多人看见。

你好，我是刘少康，来自河南周口，目前生活在浙江义乌。我正在探索个人 IP 与内容创作，希望从真实经历出发，寻找有温度的表达方式。

大学期间，我学习中医康复治疗，并曾在医院康复科实习。之后，我做过外贸客服，也服务过旅游咨询业务。不同的经历让我更加珍惜倾听和真诚沟通。

我喜欢旅行，喜欢探索各地的生活与美食，也期待认识有故事的人。

## 个人网站

[访问我的个人网站](https://lsk-000478.github.io/-/)

网站介绍了我的个人经历、个人 IP 探索方向和中医康复学习经历，并结合中医文化、本草中药、中医药膳、传统健身与 AI 内容创作，包含个人介绍视频、方法详情页和互动展示。网站使用个人照片，部分场景图片和自述视频中的人物为 AI 创意示意。

## 仓库内容

- `index.html`：网站入口。
- `dist/index.html`：个人网站首页。
- `dist/approach/`：个人 IP 探索方法的详情页。
- `dist/assets/` 和 `dist/videos/`：网站使用的图片和视频素材。

网站通过 GitHub Pages 发布。
